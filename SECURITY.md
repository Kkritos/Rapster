# Security Policy

## Supported versions
Only the latest release of Rapster receives fixes.

## Reporting a vulnerability
Rapster is a scientific simulation code and does not handle sensitive data. If you believe you have found a security issue (for example, unsafe file handling or code execution through input files), please do not open a public issue. Instead, email <YOUR_EMAIL> or use GitHub's private vulnerability reporting (Security tab → "Report a vulnerability").

You can expect a response within two weeks.
